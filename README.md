# PeoplePulse Analytics
### Employee Attrition Analysis Dashboard

PeoplePulse Analytics is a Data Science project developed to analyze employee attrition and understand workforce trends using data analysis and visualization.

The project helps identify employee attrition patterns across different departments, genders, job roles, and overtime categories through an interactive dashboard.

## Features

- Interactive Employee Analytics Dashboard
- Workforce KPI Cards
- Department-wise Attrition Analysis
- Gender-wise Attrition Analysis
- Overtime-wise Attrition Analysis
- Department, Gender and Overtime Filters
- Employee Record Search
- Customizable Column Selection
- CSV Data Download
- Business Insights

## Technologies Used

- Python
- Pandas
- NumPy
- MySQL
- Streamlit
- Plotly
- Matplotlib
- Seaborn

## Dataset

The project uses an IBM HR Employee Attrition dataset containing 1,470 employee records and 35 columns.

## Installation and Setup

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required libraries:

```bash
pip install -r requirements.txt
```

4. Run the Streamlit application:

```bash
python -m streamlit run app.py
```

5. Open the local dashboard URL displayed in the terminal.

## Project Objective

The main objective is to analyze employee attrition, identify workforce trends, and provide useful insights that can support better employee retention decisions.
